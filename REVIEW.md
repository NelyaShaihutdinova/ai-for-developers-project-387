# Критерии ревью: Календарь бронирований

## Бронирование слотов

- [ ] Забронированный слот **не остаётся доступным** для повторной записи
- [ ] Невозможно забронировать два слота с пересекающимися интервалами
- [ ] Слоты, касающиеся краями (конец одного = начало другого), **разрешены**
- [ ] Бронирование на **выходные** (МСК) — **отказ**
- [ ] Бронирование **вне рабочего окна** 09:00–18:00 МСК — **отказ**
- [ ] Бронирование **за пределами 14 дней** от завтра — **отказ**
- [ ] Начало слота **не кратно 15 минутам** — **отказ**
- [ ] Встреча не укладывается до 18:00 МСК — **отказ**
- [ ] Неактивный тип встречи — **отказ (404)**

## API

- [ ] `POST /api/bookings` валидирует email, имя, durationMinutes
- [ ] `GET /api/bookings` возвращает future записи, отсортированные по startAt ASC
- [ ] `GET /api/slots` исключает занятые интервалы
- [ ] `POST /api/meeting-types` принимает только кратные 15 минутам
- [ ] Конфликт бронирований → `409 CONFLICT`
- [ ] Валидация → `400 VALIDATION_ERROR`
- [ ] Не найдено → `404 NOT_FOUND`

## Контрактная цепочка

- [ ] TypeSpec → OpenAPI → SDK регенерированы
- [ ] `frontend/src/api/generated/` совпадает с `backend/openapi/openapi.yaml`
- [ ] CI `generate:api` проходит без расхождений

## Фронтенд

- [ ] Поле «Тема встречи» опционально, max 200 символов
- [ ] Дашборд показывает колонку «Тема» (пусто → «—»)
- [ ] Список предстоящих встреч обновляется после бронирования
- [ ] Страница meetings отображает свободные слоты

## База данных

- [ ] Миграции применяются корректно
- [ ] Foreign key `meeting_type_id → meeting_types.id` с `ON DELETE RESTRICT`
- [ ] Индекс `meeting_type_start_idx` на `(meeting_type_id, start_at)`

## Безопасность

- [ ] Нет секретов в коде
- [ ] Нет `console.log` с чувствительными данными
- [ ] Zod-валидация на всех входящих данных

## Conventional commits

- [ ] Формат: `type: description (#NN)`
- [ ] Типы: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`
